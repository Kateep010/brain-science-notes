2. 核苷酸、方向性、鹼基配對與 DNA 複製

3. 轉錄、promoter 與轉錄因子

RNA interference 中，Dicer 與 RISC 的分工是？

  1. Dicer 合成 mRNA；RISC 把 mRNA 轉譯成蛋白質
  2. Dicer 把蛋白質切成胺基酸；RISC 貼上 ubiquitin
  3. Dicer 帶著小 RNA 找目標；RISC 把雙股 RNA 切短
  4. Dicer 把雙股 RNA 切成小片段；RISC 帶著其中一股去找互補的 mRNA 並切斷或阻擋轉譯

先 Dicer 切、後 RISC 執行。選項 1 是 RNA polymerase 與 ribosome 的工作；選項 2 是蛋白質降解系統。

6. 遺傳密碼、tRNA 與轉譯

進階0908-1 32:16–33:18、54:09–56:53；0908-4 06:10–15:30先備：第 2、3、5 節

核心觀念

7. 突變的四種後果

DNA 模板股為 3'-TAC TTT CCA ATC-5'。若第二個 codon 對應的模板由 TTT 突變為 ATT，這屬於哪一類突變？

晚發型的家族性神經退化疾病（四五十歲後才發病），依老師的說明，較常見的突變型態與理由是？

  2. Frameshift，因為只影響一個胺基酸

  1. phosphatase 把磷酸基加到蛋白質上，kinase 把它移除
  2. 磷酸基來自 DNA 的骨架
  3. kinase 利用 ATP 把磷酸基加到蛋白質上；可在一分鐘內完成，適合當快速開關

5.（B 第 1 題）睡醒中樞理論如何證明？

答題要點

6.（B 第 2 題）造成自然睡及醒的兩種啟動因子？

8.（B 第 4 題）醒、N1、N2、N3、REM 的腦波、肌電、眼動變化？

5. DIC 與看圖辨識

進階1006-3 00:00–14:19先備：第 4 節

核心觀念

  • DIC(differential interference contrast)的 differential 是微分：偵測相位的梯度（相鄰兩點相位差多少）。1950 年代發明，發明者沒拿到諾貝爾獎。1006-3 00:251006-3 02:15
  • 流程：polarizer 把光變成偏振光 → Nomarski（或 Wollaston）prism 分成偏振垂直、位置只差一點點的兩道光 → 穿過樣本相鄰兩點累積不同相位 → 第二個 prism 合併 → analyzer 把偏振態改變轉成亮暗。1006-3 02:461006-3 03:361006-3 06:46
  • 老師的算術：背景相位 0、細胞內 1，輸出為右減左。0−0=0（灰）；右進細胞 1−0=+1（亮）；都在細胞內 1−1=0；右出左在 0−1=−1（暗）。所以一邊亮一邊暗、中間與背景同灰。1006-3 07:351006-3 08:031006-3 08:14
  • 影像立體是假的，細胞邊緣剛好是相位變化最大處。阿米巴原蟲亮視野下是扁的，DIC 下「凸起來」。1006-3 01:061006-3 01:31
  • 貴：整套十幾萬（現在稍便宜），偏振片不貴，貴在兩個 prism；所以 phase contrast 更普及。1006-3 09:201006-3 10:20

  • 有顏色 ≠ bright field：看背景與邊緣特徵。免疫染色的切片也是 bright field（背景亮）。

同一樣本、四種成像法：真實影像對照（期中考重點：看圖辨識）

老師預告考試會給網路上的新圖，問是哪一種顯微鏡。最好的練習，是看同一種樣本在不同方法下長什麼樣。下面四張是同一批舟形矽藻(Pleurosigma angulatum，一種單細胞藻類，外殼是透明的二氧化矽)，由同一位攝影者依序以四種照明方式拍攝。口訣：亮視野=白背景；暗視野=黑背景；相位差=灰背景加光暈；DIC=灰（或單色）背景加浮雕、一邊亮一邊暗。

  2. Phase plate

  4. Nomarski prism

6. 螢光原理與 filter cube

進階1006-3 14:25–27:00先備：第 2 節（波長與能量）

核心觀念

  • 螢光顯微鏡是現代生物學最常用的顯微鏡；confocal 與 two-photon 都是它的延伸。Seminar 裡五顏六色的細胞核、高基氏體、ER，細胞本身不會發那些顏色。1006-3 14:291006-3 14:38

  • 波長不同，所以用 filter 擋掉短波長激發光，就能只看長波長螢光。1006-3 17:481006-3 18:27
  • 光源：短波長，如水銀燈（mercury lamp）。激發光與螢光走同一顆物鏡，所以用 dichroic mirror：短波長反射、長波長穿透。1006-3 20:171006-3 22:00
  • 研究用相機大多黑白：每色各拍一張再用電腦套色疊合，論文裡的彩色螢光圖幾乎都是套色。1006-3 24:091006-3 25:00
  • 多頻帶 cube 一個就能同時過三色，眼睛或 iPhone 可一次看三色，但各波段都損失強度、激發不能太強，所以做研究仍單色分次拍再疊。1006-3 25:441006-3 26:37

老師強調

  • 考試Filter cube 三元件:excitation filter（例：只讓 300–400 nm 通過）、dichroic mirror（400 nm 以下反射、以上穿透）、emission filter（只放行螢光波段）。每種顏色一個 cube。1006-3 22:501006-3 23:091006-3 23:38
  • 考試DAPI 藍，染 DNA，所以細胞核藍色；FITC 綠，約 490 nm 激發、530 nm 放綠光；Texas Red 紅。三色搭配。1006-3 25:531006-3 19:101006-3 26:14
  • FITC 是最早以有機合成做出的螢光分子，合成的化學家得諾貝爾化學獎（不只因這項）。1006-3 18:591006-3 19:29

  • 放射光波長比激發光長、能量較低；不是較短。

  1. 反射長波長螢光、讓短波長激發光穿透
  2. 反射短波長激發光到樣本,讓長波長螢光穿透到偵測端

  4. 擋住失焦的螢光

8. 厚樣本怎麼辦:confocal 與 two-photon

  • 缺點:慢,掃一張可能二十秒,一個樣本常掃半小時。1006-3 43:16
  • Two-photon:兩顆光子在極短時間內同時打到同一分子,能量相加。1930 年代提出,1960 年代雷射發明後證實。350 nm 的分子改用 700 nm(紅到近紅外)即可,仍放出一顆普通螢光。1006-3 45:401006-3 46:181006-3 46:35
  • 教室與廁所比喻:光子要擠到極小空間才有機會同時撞到;只有焦點光強夠高,所以只有焦點發光。老師給的「同時」是約 10⁻¹⁸ 秒,只當作「極短」。1006-3 47:211006-3 47:501006-3 48:01
  • 三個好處:(1)不需要 pinhole(單光子是「凡走過必留下痕跡」,雙光子焦點外根本沒螢光);(2)穿得深:短波長易被散射(天空藍、黃昏太陽橘),近紅外散射少,且 700 nm 附近是水、黑色素、血紅素吸收的凹陷區;(3)紅外光能量低,對組織傷害小。1006-3 48:511006-3 50:241006-3 52:291006-3 53:01
  • 應用:把小鼠頭骨磨薄或開窗,直接看活腦皮質到約 500 µm(第五層),看神經突起細微構造、血管、免疫細胞,MRI、PET 看不到。1006-3 53:221006-3 54:09

  • 考試成像深度:confocal 約 150 µm,two-photon 約 400–500 µm(約三倍,約小鼠 cortex 厚度)。1006-3 51:131006-3 53:22
  • 考試Two-photon 深但解析度不如 confocal;樣本不太厚用 confocal,活體或很厚的組織才用 two-photon。1006-3 54:311006-3 54:41

易混淆

  • 近紅外光是散射較少,不是沒有;「穿得深」不等於「解析度高」。
  • 雙光子波長是單光子的兩倍(能量減半),放出的仍是一顆螢光光子(吃兩顆放一顆)。
  • 偏振片是 DIC、近紅外是 two-photon、pinhole 是 confocal,別互相套用。
補充(老師沒講公式,不考):為什麼 two-photon 解析度較差——繞射極限

任何透鏡都無法聚成無限小的點,能分辨的最小距離約為 d = λ/(2·NA)。雙光子用的波長約是單光子的兩倍,光點自然比較胖。這和雷達波束寬、衛星繞射極限是同一個物理。下方計算機供你玩,只是補充:固定 NA = 1.0,把波長從 500 拉到 950 nm,看兩個相距 250 nm 的點從分得開變成糊在一起。

想在活小鼠大腦皮質約 400 µm 深處觀察神經元,應選?理由?

  1. Confocal,因為解析度最好
  2. Phase contrast,因為不需染色
  3. Confocal,因為可見光穿透比紅外光深
  4. Two-photon,因為近紅外光散射與吸收較少,可達約 400–500 µm

短波長易被散射與吸收;confocal 約 150 µm。

9. 本週速記卡

入門整週統整
細胞體大小與肉眼極限?
細胞體約 10–30 µm;肉眼約 0.1 mm = 100 µm。MRI、PET 看不到單一細胞。
物鏡與目鏡各形成什麼像?
物鏡:倒立放大實像(相機放這);目鏡:當放大鏡,放大虛像。
為何活細胞用倒立顯微鏡?
物鏡在皿下,不必開蓋或把鏡頭泡進培養液,保持無菌。
辨識口訣:bright / dark field
Bright:背景亮、樣本有顏色。Dark:背景黑、樣本亮。
辨識口訣:phase contrast
背景灰、細胞外圍一圈亮光暈。零件:condenser annulus + phase plate,要 match;Ph 不是酸鹼度。
辨識口訣:DIC
背景灰、一邊亮一邊暗的假立體。零件:polarizer、analyzer、兩個 Nomarski/Wollaston prism。綠色纖毛蟲陷阱題=DIC。
H&E 各染什麼?
Hematoxylin(正電)→ DNA → 細胞核深藍;Eosin(負電)→ 蛋白質 → 細胞質粉紅。
Nissl 與 Golgi
Nissl:鹼性染料染 RNA,分灰質與白質。Golgi:重鉻酸鉀+硝酸銀,只染 5–10% 神經元但完整,導出神經元學說(1906 諾貝爾獎)。
Stokes shift
放射光比激發光波長長(能量低),所以可用濾光片分開。
Filter cube 三元件
Excitation filter、dichroic mirror(短反射長穿透)、emission filter。一色一 cube。
DAPI / FITC / Texas Red
DAPI 藍(染 DNA、細胞核);FITC 綠(約 490 激發/530 放射);Texas Red 紅。
間接免疫螢光
不標記的一級抗體(小動物)認抗原;帶螢光的二級抗體(大動物,認一級抗體)。便宜通用、訊號放大。
GFP 的優勢
水母蛋白,送基因進去細胞自己做,活細胞可看,可融合追蹤位置;2008 諾貝爾獎。
Confocal vs two-photon
Confocal 必備 pinhole、約 150 µm、解析度較好;two-photon 不需 pinhole、約 400–500 µm、近紅外、解析度較差。

一張未染色活細胞影像:背景灰色,每顆細胞外圍都有一圈明亮光暈。最可能是哪一種?

  1. Bright field
  2. Dark field
  3. Phase contrast
  4. DIC

灰背景加外圍亮光暈是 phase contrast;DIC 是一邊亮一邊暗。

相位差顯微鏡必須具備且互相配對的兩個零件是?

  1. Polarizer 與 analyzer
  2. Condenser annulus 與 phase plate
  3. Excitation filter 與 emission filter
  4. Pinhole 與單點光偵測器

選項 1 是 DIC,3 是螢光 filter cube,4 是 confocal。

H&E 染色中細胞核呈深藍色,原因是?

  1. Eosin 帶負電,與細胞核內帶正電的蛋白質結合
  2. 細胞核本身含藍色色素
  3. Hematoxylin 與 RNA 反應生成黑色銀沉澱
  4. Hematoxylin 帶正電,與帶負電的 DNA 結合

核酸酸根帶負電;生成黑色銀鹽的是 Golgi 染色。

「神經細胞全部融合成連續網路」的舊模型,最無法解釋什麼?

  1. 神經用電傳訊號
  2. 神經傳導是單方向的
  3. 神經纖維可以很長
  4. 神經細胞含有離子

連通的電解液管子刺激後應往兩邊跑;神經元學說加神經傳導物質與受體才解釋單向性。

配合題:下列「染劑—顏色—標記對象」何者完全正確?

  1. DAPI—藍—DNA(細胞核)
  2. DAPI—綠—蛋白質
  3. FITC—藍—DNA
  4. Hematoxylin—粉紅—細胞質

FITC 綠;hematoxylin 深藍染核;粉紅細胞質是 eosin。

同時觀察 DAPI、FITC、Texas Red 三種染劑,研究上最常用的做法?

  1. 彩色相機配多頻帶 cube 一次拍完
  2. 拿掉濾片用白光照明
  3. 三個 filter cube 分別拍三張黑白影像,再用電腦套色疊加
  4. 只用一個 excitation filter 靠相機分辨顏色

多頻帶 cube 各波段損失強度,研究上不常用。

關於 confocal 與 two-photon,何者「錯誤」?

  1. Confocal 深度約 150 µm,two-photon 約 400–500 µm
  2. Two-photon 解析度比 confocal 好,所以薄切片也應優先使用
  3. Two-photon 用較長波長,對組織傷害較小
  4. Two-photon 不需要 pinhole

老師明講 two-photon 深但解析度不如 confocal,樣本不太厚用 confocal。

某分子單光子激發波長 350 nm,改用雙光子激發,應使用約多少波長的光?

  1. 175 nm,兩顆波長相加
  2. 350 nm,只是強度加倍
  3. 525 nm,取激發與放射波長平均
  4. 700 nm,每顆光子能量減半(波長加倍),兩顆相加才等於一顆

光子能量與波長成反比;700 nm 在紅到近紅外。
