# 115-1 基礎腦科學概論 互動筆記

國立陽明交通大學腦科學研究所「基礎腦科學概論」第 1–5 週課堂筆記（互動網頁版），為非生物背景（大氣科學）的跨領域讀者撰寫。

- 開啟方式：直接瀏覽 GitHub Pages，或下載 `index.html` 用瀏覽器開啟（影片與 3D 分子需要網路）。
- 功能：章節導覽與搜尋、名詞提示、逐步流程、小測驗與翻卡、嵌入 3D 解說影片、可旋轉的 3D 分子結構（RCSB PDB + 3Dmol.js）、互動小工具、閱讀進度、深淺色模式。

本筆記依課堂錄影語音轉錄與授課簡報重新整理，僅供個人學習；內容若與老師講授或教科書有出入，請以老師與教科書為準。不含課堂錄影、逐字稿與簡報原檔。
